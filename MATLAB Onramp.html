Summary
This video walks through some features of the MATLAB Desktop:
  • When you start MATLAB, the default layout includes the Command Window, Workspace panel, and Files panel.
  • The Command Window executes one line of code at a time.
  • For sequential command execution, create a live script. Live scripts allow you to run multiple commands, view outputs, add descriptions, save your work, and share with others.
  • Customize the MATLAB desktop to fit your workflow by customizing the windows.
Transcript
When you start MATLAB, the default layout contains three panels-- the Command Window, Workspace panel, and Files panel. In the Command Window, you can enter MATLAB commands and they're executed as soon as you hit Enter. The activities you've completed so far worked this way.

Some commands create new MATLAB variables. And these variables are displayed in the Workspace panel. Entering commands one by one in the Command Window is a quick way to try something out and see the result.

However, solving problems often requires a sequence of commands. You can organize all your commands and their output together in a live script.

To create a live script, click New Live Script in the toolstrip. Enter your commands in the gray code box. Switch to text mode to add some description. You can now run multiple commands at once by clicking the Run button, which evaluates all the commands in order.

By default, the output appears on the right. You can change where to display output, such as using output inline, where output appears immediately after the command that created it. Either way, you can see how your code relates to the output.

If you click a result in the output pane, the command that created it is shown in the editing pane and vice versa. Clicking items in the output pane can also make them interactive. You can also break your script into sections, allowing you to run just a portion of your code. To run a single section, click the Run Section button.

Saving your live script saves the code output and descriptions. You can share this interactive document with other MATLAB users so they can understand your ideas, run your code, and experiment for themselves. Or to share your results with anyone, regardless of whether they have MATLAB, you can save your live script as a document viewable outside of MATLAB.

Different people have different working styles, so you can customize the desktop as you see fit. By default, the Files and Workspace panels are grouped so you can see them side by side. Drag the panel's sidebar icon to ungroup it or move it to other sidebars on the desktop. You can also minimize and restore a panel by clicking its icon.

There are other panels available. And as you work in MATLAB, new panels may be opened for you. If you ever want to return to the default layout, click Layout in the toolstrip.

In the rest of this course, you'll use live scripts to complete tasks. The Command Window and Workspace panels are minimized, but you can open them at any time to try out commands or view variables.

5.1 Indexing

Video: Video

Summary
Indexing allows you to extract and modify array values.
  • Use one index to access elements in a vector. For example, x(3) extracts the third element of vector x.
  • For matrices, use two indices (row, column). For example, A(2,3) extracts the element at the second row, third column of the matrix A.
  • Extract ranges using a colon. For example, A(:,3) extracts all rows of the third column.
Transcript
Every variable in MATLAB is an array. So to program in MATLAB, you'll need to know how to work with arrays.

Referring to elements in an array is the first step. This is called indexing. Indexing is how you extract and modify values in arrays. The position of a value inside any array is called its index. You can use the index to extract particular values. For example, if you want the third element of the vector x, you type x followed by the index 3, enclosed in parentheses. We usually read this as "x of 3".

You can also extract a range of values by using a colon with the first and last indices of the range. If you want to extract elements from a matrix, specify two indices instead. The first index is the row number, and the second is the column number. It's pretty common that you want to extract a whole row or a whole column from a matrix. When you use a colon on its own as an index, it stands for all, as in all the rows or all the columns. For example, x(1,:) extracts the first row and all the columns. Similarly, x(:,3) extracts all the rows of the third column.

There's a lot more you can do with indexing, but for now, remember that matrix indexing is row,column and vectors only need one index.

All the scripts you've seen so far execute commands in order from beginning to end. But what if you only wanted to execute a line of code if the variable x is positive? Video: Repeat Code with Loops

Open the video in a new tab

If the Brightcove player is difficult to use, review the summary and transcript below. You can also open the video in a new tab.

Summary
To repeat commands, use a for loop, which iterates over a range of values. For simple operations, leverage MATLAB's array capabilities to avoid loops. For complex tasks, for loops help repeat actions.
Transcript
Sometimes, instead of skipping code, you want to repeat a set of commands multiple times. If you start copying, pasting, and modifying your code, well, it's probably time to use a loop.

The most common kind of loop is a for loop, which uses the for keyword. The block of code within the loop will be repeated multiple times based on the loop index. For example, x = 1:5 creates a loop index named x with the values 1 to 5.

In the first pass of this loop, the value of x is 1. In the second pass of the loop, the value of x is 2, and so on. In each pass, x changes value, stepping through each of its values. Once x gets to the last value, the loop executes one last time with the final value and then moves on to the code after the loop.

If your code is very simple, like just calculating the square of a bunch of numbers, you probably don't need to use a for loop. Remember that MATLAB works with arrays naturally. So you can use MATLAB's array capabilities to write clean code without having to use a loop. For cases when it's not so simple, for loops give you a way to repeat a set of tasks across collections of data.
